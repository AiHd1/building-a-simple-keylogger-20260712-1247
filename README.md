# Simple Keylogger

## Description
This is a simple keylogger built in Python. It captures keystrokes and logs them to a file. This project is for educational purposes only. Unauthorized use of keyloggers is illegal and unethical.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/simple-keylogger.git
   cd simple-keylogger
   ```
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage
Run the keylogger with the following command:
```bash
python main.py --output log.txt
```

### Options
- `--output`: Specify the output file where the keystrokes will be logged (default: `keylog.txt`).
